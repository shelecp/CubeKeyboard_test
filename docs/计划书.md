## 1. 项目定位

本项目是一个 **Web 端 3D 魔方键盘软件原型**，用于验证：

- 3D 魔方展示与观察；
- 键盘按键触发魔方层扭转，扭转序列映射为字符；
- 鼠标对魔方格子的"模拟触摸"：悬停焦点、点击取字；
- 格子唯一编号体系与编辑模式；
- 多套输入法（26键拼音 / 双拼 / 五笔预留 / 纯英文 / 九宫格拼音）与各自的扭转规则表；
- 页面内悬浮输入法栏接收字符并组词、出候选。

本项目 **不包含真实硬件读取**，**不调用系统级输入法**，也 **不调用浏览器真实陀螺仪**。"方向模拟"只是用当前 3D 相机视角模拟"魔方此刻哪个面朝上、哪个面朝向用户"。

## 3. 一、目标 —— 基线清理与键位根治

### 3.1 键位固定（绝对要求）

六面键位固定为 **a / s / d / f / r / v**，布局如下：

```text
        R（顶面 U）
  A（左 L） S（正 F） D（右 R） F（背 B）
        V（底面 D）
```

另有 j / k / l 三个中层键（竖 M / 横 E / 前后 S）。`Shift + 按键 = 逆时针`。

### 3.2 根治"键位漂移"隐患

- 历史事故：v2 配置里的 `migrateConfig` 键位迁移链把旧存档的 r/v 静默改写成 e/c，导致用户发现"键位莫名其妙变了"。
- 本版处理：
  - 删除全部键位迁移代码；
  - 存储 key 升级为 `cube-keyboard-config-v3`，旧 localStorage 配置直接作废、不做任何静默改写；
  - 键位唯一权威来源为 `src/mapping/defaultConfig.js`（文件头注释明确声明）；
  - 清扫所有写过 e/c 键位的注释、提示与文档；今后键位变更只改权威来源 + 文案，**禁止再写迁移代码**。

### 3.3 旧计划书归档

`docs/计划书.md`（v0.3）压缩为 `docs/计划书-2026-08-16.zip`，同目录写 `计划书-2026-08-16-已失效.txt`。新计划书（本文件）模仿旧版风格重写。

## 4. 一、目标 —— UI 重构

### 4.1 侧边栏抽屉把手（已确认方案）

- 按钮成为侧边栏容器的一部分，吸附在侧边栏**右缘外侧**（略微压边）；
- 展开 / 收起共用**同一个 transform 动画**，全程同步、不再分层遮挡；
- 收起后侧边栏完全滑出屏幕，把手恰好停在**屏幕左缘**，可再次展开；
- 删除旧的 z-index 分层方案（按钮 z:3 压侧栏 z:2）。

### 4.2 悬浮输入法栏

- 输入法栏（状态、组词预览、分页候选、输出区）从侧栏抽出为**悬浮可拖动条**（右下角）；
- 所有输入法共用同一条栏；格子编辑弹窗与其同风格配色；
- 候选支持鼠标点选、数字键 1-9 选当前页、‹ › 翻页。

### 4.3 侧栏重排

侧栏面板重排为：运行自检 → **输入法（下拉切换）** → 扭转规则（含录制） → **格子与文字（编辑模式）** → 参考系 → 键盘映射 → 操作记录 → 动作。旧的"输入模式（扭转序列/九宫格）"二选一按钮删除——选择九宫格输入法即进入九宫格模式。

## 5. 一、目标 —— 输入法体系重构

### 5.1 配置文件（每个输入法一个 JSON）

```text
src/configs/ime/
├─ pinyin26.json   26键拼音（完整实现）
├─ shuangpin.json  双拼（小鹤方案，简版）
├─ wubi.json       五笔（预留）
├─ english.json    纯英文（完整实现）
└─ t9.json         9键拼音（入口声明，实现实体在 src/t9/）
```

字段：`id / name / engine / enabled / description / defaultRules / config`。
`defaultRules` 即该输入法自己的默认扭转规则表；用户增删的规则按输入法分表存于 `config.imeRules[profileId]`，**切换输入法即切换规则表**，互不干扰。

### 5.2 默认扭转规则表设计（所有输入法可独立修改）

字母区统一为"**两段扭转 = 一个字母**"：

```text
第一段选行：U / E / D        第二段选列：L / M / R / F / B
第二段带 ' 为逆时针
a=U L  b=U L'  c=U M  d=U M'  e=U R  f=U R'  g=U F  h=U F'  i=U B  j=U B'
k=E L  l=E L'  m=E M  n=E M'  o=E R  p=E R'  q=E F  r=E F'  s=E B  t=E B'
u=D L  v=D L'  w=D M  x=D M'  y=D R  z=D R'
```

26 个字母恰好占满 3×5×2 槽位；全部等长 ⇒ "最长后缀匹配"天然无前缀歧义，跨界连打也不会误命中。
功能键独立占用前后中层 S：`S → ␣`、`S' → ⌫`、`S2 → ⇥`。

### 5.3 实现范围（已确认）

| 输入法 | 状态 | 说明 |
| --- | --- | --- |
| 26键拼音 | 完整实现 | 字母累积成拼音，候选点选 / 数字键选择 |
| 纯英文 | 完整实现 | 字母直接上屏 |
| 9键拼音（九宫格） | 完整实现 | 独立模块 src/t9/，见第 7 章 |
| 双拼（小鹤） | 简版实现 | 两键定音节，映射表存于 profile；简版一次处理一个音节 |
| 五笔 | 预留 | 规则表生效、字母只记录展示，字根-字词库接口留好 |

### 5.4 规则录制（类快捷键录制）

扭转规则面板提供「录制」按钮：开启后直接按 a/s/d/f/r/v（+Shift 逆时针）扭层，扭转序列实时填入输入框；再点一次停止。也可手动输入序列。规则列表每条支持「编辑」（序列可重新录制）与「删除」。录制期间规则引擎暂停输出。

## 6. 一、目标 —— 模拟触摸与编辑模式

### 6.1 贴纸唯一编号体系

- 复原态下按"从外侧正视该面"的阅读顺序给 54 个贴纸编号：`F1..F9、U1..U9、D1..D9、L1..L9、R1..R9、B1..B9`；
- 编号绑定在小块上、随层旋转**永不改变**；旋转导致"正面"变化时一律以编号定位，不会混淆；
- 实现位于 `CubeModel`（`assignStickerIds / stickerAt / cellOwner`）。

### 6.2 贴纸文字渲染

- CanvasTexture 覆层懒创建、变更才重绘，跟随小块旋转；
- 超长文字默认只显示前 4 字符 + `…`；
- `config.cells`（编号 → 文字）为唯一数据源，默认给 F 面 QWERTY 演示。

### 6.3 模拟触摸

- 鼠标悬停格子 → 焦点高亮动画（呼吸式描边贴片，单个复用，rAF 节流 raycast）；
- 移到魔方之外空白处 → 焦点动画消失；
- 普通模式点击格子 → 输出该格文字到输入法栏；点击与旋转拖拽用位移/时长阈值区分；
- 九宫格模式下模拟触摸关闭：贴纸文字消失、只显示九键键位、输入只认旋转。

### 6.4 编辑模式

- 侧栏「进入编辑模式」按钮切换；编辑模式下点击格子弹出**可拖动编辑浮窗**：
  - 顶部显示唯一编号（如 `格子 F5`）；
  - 输入框预填当前文字；保存 / 取消按钮；**回车即保存**；Esc 或 × 取消；
  - 可同时开多个，点谁谁置顶；
- 魔方仍可旋转；编号跟随小块，不会因旋转混淆；
- 编辑模式暂停规则输出与触摸输出（只保留旋转）；
- 单格保存即时更新贴纸显示（暂存）；侧栏**总保存**按钮统一写入 localStorage；
- 刷新后已保存内容保留；未保存内容提示"有未保存的修改"。

## 7. 一、目标 —— 九宫格（独立 T9 模块）

### 7.1 交互模型（已确认）

- **没有"按下"动作，只能通过旋转定位**；
- 正面（方向模拟 = 相机视角正面）的 9 个格子按标准电话键盘定义为 9 个键：

```text
1(标点)  2abc   3def
4ghi     5jkl   6mno
7pqrs    8tuv   9wxyz
```

- **两次旋转定位一个格子**：一次横向层（U/E/D，定行）+ 一次纵向层（L/M/R，定列），不分先后、不分顺逆；两层在当前正面的交点即唯一格子，直接输出该格的数字键；
- 同轴连转以最后一次为准；F/B 转动不参与定位；
- 键按"当前正面位置"定义，不绑定具体贴纸；旋转/换面后 9 个键的文字**实时跟随新正面**显示。

### 7.2 完整九键拼音输入法

- 数字缓冲（上限 12 位）→ 拼音音节 DP 切分（多切分并存）→ 候选；
- 候选为各切分"末音节"常用字的**轮询合并**（按字频排序），保证每种切分的高频字都进首页；
- 组词预览显示音节切分（如 `64426 → ni'hao（另有 11 种切分）`）；
- 候选点选 / 数字键选择 / ‹ › 翻页 / 退格删一位 / 清空；
- 数字 1 键 = 常用中文标点；
- 字库 `src/t9/t9-dict.json`：406 音节 × 前 5000 高频字（Jun Da 现代汉语字频表，去声调、ü→v），约 33KB，构建期内联，无运行时依赖；
- 生成脚本 `scripts/gen-t9-dict.mjs`（数据副本 `scripts/data/charfreq-ModernMO.txt`）可重跑。

### 7.3 与主系统的隔离（冲突处理）

- 九宫格在下拉里表现为"9键拼音"选项，**实现实体完全独立在 `src/t9/`**，通过动态 `import()` 挂载；
- 选中时：接管输入法栏回调、暂停规则引擎（扭转只旋转不吐字）、隐藏贴纸文字、显示 9 键键位、强制切到方向模拟参考系（退出时恢复）；
- **验收标准：删除整个 `src/t9/` 目录并去掉下拉项后，其余功能零影响。**

## 11. 对外接口（window.CubeKeyboard 增量）

v0.3 的魔方 / 配置 / 规则 / 参考系接口延续（其中九宫格贴纸 `triggerSticker / setStickerCell / registerStickerMap` 已删除，由格子编号接口取代）。新增 / 变化：

```js
// 输入法 profile
CubeKeyboard.activateProfile("shuangpin", defaultRules); // 切换输入法（规则表随动）
CubeKeyboard.getActiveProfile();
CubeKeyboard.setEngineSuspended(true);   // 暂停规则引擎（九宫格/录制/编辑模式）
CubeKeyboard.isEngineSuspended();

// 格子文字（贴纸唯一编号）
CubeKeyboard.setCellText("F5", "你好");
CubeKeyboard.getCellText("F5");
CubeKeyboard.clearCellText("F5");
CubeKeyboard.listCells();               // { F5: "你好", ... }
CubeKeyboard.listCellIds();             // 54 个编号
CubeKeyboard.saveCells();               // 编辑模式"总保存"
CubeKeyboard.triggerCell("F1");         // 模拟触摸：输出该格文字
CubeKeyboard.applyCellsToRenderer();    // 全量刷新贴纸文字

// 事件（新增）
CubeKeyboard.on("turn", ({ face, dir, logical }) => {});   // 每次扭转（录制/九宫格用）
CubeKeyboard.on("cellschange", (cells) => {});             // 格子文字变化
CubeKeyboard.on("cellssaved", (cells) => {});              // 总保存完成
```

配置结构（v3）新增字段：`activeIme`、`imeRules`（按输入法分表）、`cells`（编号 → 文字）；`rules`、`stickerMaps`、`version:1` 已废弃。

## 15. v0.4.1 修订记录（2026-09-03）

本版在 v0.4 基础上按用户反馈修订，**以下条目优先级高于前文对应描述**：

### 15.1 九键拼音与九宫格模式彻底分离（重要）

- **九键拼音**是与 26键 / 双拼 / 五笔 / 英文**平级的正式输入法**（`src/configs/ime/ninekey.json`，engine `ninekey`）。其规则表输出为字母组 `abc/def/…/标点`，**输出锁定不可改**（只能改前面的扭转层；添加/删除按钮隐藏、输出框禁用）。
- **九宫格模式**是完全独立的实验功能：入口为**页面右上角「九宫格模式」按钮**，不再是输入法下拉项。开启后侧边栏自动收起并**锁定不可展开**、规则引擎暂停、贴纸文字隐藏、正面 9 格显示键位；再点退出并恢复。
- 九键拼音引擎与字库归位到 `src/ime/`（`t9Engine.js` + `t9-dict.json`），被九键输入法和九宫格模式**共用**；`src/t9/` 只剩实验模块 `T9Module.js`，经 `import.meta.glob` 懒加载。**删除 `src/t9/` 后九宫格按钮自动隐藏，九键拼音输入法及其他功能零影响。**

### 15.2 侧边栏把手改为"一体导轨"

- 把手不再是悬浮在侧栏上方的小按钮，而是侧边栏右侧一条 36px 导轨的一部分，与面板同属一个动画容器（同一 transform），**不遮挡面板滚动条**。
- 收起后导轨留在屏幕左缘可再展开；九宫格模式下导轨隐藏（锁定）。

### 15.3 悬浮输入法栏

- 删除"收起/展开"按钮（用户反馈无必要且偶发失灵）。
- 支持按住标题栏任意拖动 + 拖拽四边/四角**窗口式缩放**。
- 整条栏 `user-select: none`，避免左键拖动被浏览器识别为拖选文字。

### 15.4 格子与文字：保存改为右上角浮动按钮

- 删除侧栏内"总保存"按钮；有未保存修改时**页面右上角出现"保存"按钮**，点击统一持久化并隐藏。

### 15.5 动作面板重构（配置相关）

- 「重置魔方」→「重置魔方方向」。
- 「重置所有配置」→「重置所有输入法扭转规则」；新增「重置当前输入法扭转规则」。
- 「导出配置」→「导出当前输入法扭转规则」：导出文件带输入法标识（如 `cube-keyboard-rules-wubi.json`，内含 `ime` 字段）。
- 新增「导入当前输入法扭转规则」：选择文件后，若文件输入法标识与当前不匹配，**页面 toast 提示拒绝**；匹配才导入。
- 移除旧的"整份配置导入/导出"按钮（功能过时）。

### 15.6 规则记法图例

- 「扭转规则」面板直接显示记法图例：U/D/L/R/F/B = 顶/底/左/右/正/背，M/E/S = 竖/横/前后中层，解决"E 是什么"的疑问。

### 15.7 右键手势劫持缓解

- 在 canvas 上对右键 `mousedown` 与 `contextmenu` 均 `preventDefault`，尽量阻止浏览器/扩展把右键拖动识别为鼠标手势。注：部分浏览器手势扩展无法被网页完全拦截，属环境限制。

### 15.8 测试同步

- Node 逻辑测试 9 个（test-t9 路径更新、test-ime 增加九键引擎用例）。
- Playwright E2E 增至 **22 个**：新增九键拼音输入法用例、规则重置/导出/导入(含不匹配拒绝)用例、九宫格模式按钮与侧栏锁定用例、右上角浮动保存用例；把手动画断言改为一体导轨。

### 15.9 性能优化（针对"运行卡、拖慢整机"）

- **按需渲染**：删除常驻 rAF 循环，改 `invalidate()` 事件驱动；空闲时 0 次 GPU 绘制（实测空闲 3s render=0，仅相机/扭转/悬停/贴纸变化时出帧）。根治持续占用 GPU 导致的核显降频与整机发烫。
- **关闭 `preserveDrawingBuffer`**（省显存与合成开销）；`main.js` 相应移除像素采样诊断（能力检测用独立画布，不受影响）。
- **设备像素比封顶 1.5**；去掉 `high-performance`，避免双显卡笔记本被强制独显发热。
- **消除每帧 GC**：`getSimulatedViewFaces` 复用临时向量；贴纸/高亮纹理 `generateMipmaps=false`。
- **拾取健壮性**：按需渲染下世界矩阵仅在 render 时更新，故 `_pickAt` 前强制 `updateMatrixWorld(true)`，避免首帧前 raycast 命中错误。
- 修复关键 bug：构造函数中 `_loop` 的 bind 必须在任何 `invalidate()` 之前（`_onResize` 会触发 invalidate），否则 rAF 收到未绑定回调、`this` 为 undefined 抛错、`_frameRequested` 永久卡死导致整屏不刷新。
- 验证：9 Node + 22 E2E 全绿；空闲/交互/悬停/离开渲染次数实测符合预期；两帧对比确认有绘制且动画生效、无黑屏。

### 15.10 移动端与小尺寸 UI 优化

- **修复输入法栏被拉伸**：`ImeBar._placeInitial` 之前只设 `left/top` 未清 CSS 的 `right/bottom`，四边同时钉住导致栏被撑满视口（各尺寸都受影响，手机最严重）。现在放置时清 `right/bottom`，并在矮视口按实际高度夹取，避免底部裁切；窗口尺寸变化时若用户未手动挪动则重新停靠。
- **修复输入法栏贴底/拖出屏幕**：默认右下角但四周留白（底边距 20px，不贴浏览器底部）；新增 `_clampToViewport`，拖动与缩放后都夹取，保证整栏始终完整可见、四周留 ≥8px 边距，不会再"对齐底部"或拖出视口。
- **魔方避让遮挡面板**：`#cube-container` 增加 `--cube-shift-x/y` 平移（桌面侧栏展开右移 183px、手机抽屉展开上移 14vh；九宫格模式与收起态不偏移）。canvas 用 CSS transform 平移，`getBoundingClientRect` 随之变化，故 raycast 命中不受影响。顶部提示条同步右移。
- **手机底部抽屉重排**：容器改纵向 flex，把手导轨用 `order` 提到顶部横条、面板在下可滚，收起只露 40px 导轨；修复导轨压住标题、把手被 IME 栏挡住够不到的问题。
- **手机隐藏顶部键盘提示条**（触屏用不到且窄屏被裁切）；IME 栏手机改为顶部紧凑停靠、输出框单行。
- 验证：390×844 / 740×360 / 820×1180 多尺寸截图确认布局正常；触摸/编辑用例先收起侧栏使魔方回中，22 E2E 全绿。
