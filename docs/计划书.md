# 魔方键盘（Cube Keyboard）项目计划书

> 版本：v0.3
> 日期：2026-08-16
> 状态：目标已确认，代码与 README 已同步到本版。

## 1. 项目定位

本项目是一个 **Web 端 3D 魔方键盘软件原型**，用于验证：

- 3D 魔方展示与观察；
- 键盘按键触发魔方层扭转；
- 扭转序列 / 九宫格贴纸映射为字符；
- 页面内虚拟输入法接收字符并做出简单反应；
- 手动模式与方向模拟模式驱动键盘层映射变化。

本项目 **不包含真实硬件读取**，**不调用系统级输入法**，也 **不调用浏览器真实陀螺仪**。所谓“方向模拟”只是用当前 3D 相机视角模拟“魔方此刻哪个面朝上、哪个面朝向用户”，并不是真实调用硬件传感器。

## 4. 当前实现规范

### 4.1 3D 展示与交互

- 使用 Three.js + WebGL 渲染三阶魔方。
- 相机围绕魔方中心 360° 旋转，不限制俯仰角。
- 鼠标左键 / 单指：旋转。
- 鼠标右键 / 中键：平移。
- 双指：平移 + 捏合缩放。
- 滚轮：缩放。
- XYZ 参考线固定在世界原点，可开关。
- 平移后旋转中心仍保持在魔方中心。
- 页面级横竖滚动条隐藏。

### 4.2 键盘与层映射

默认键位：

```text
            E（顶面 U）
        J（竖中层 M）
A（左面 L） S（正面 F） D（右面 R） F（背面 B）
        K（横中层 E）
            C（底面 D）
  另外：L 键 = 前后中层 S
```

- 直接按键 = 顺时针扭转该面。
- `Shift + 按键` = 逆时针扭转该面。
- `turnRelative()` 按当前参考系把用户视角逻辑面解析为世界面。
- 参考系变化后，键盘实际扭转层跟随变化。

### 4.3 规则引擎

- 支持两类映射：
  - `turn-sequence`：扭转序列 → 字符；
  - `sticker`：九宫格贴纸坐标 → 字符。
- 扭转序列采用“缓冲 + 最长后缀匹配”。
- 每次扭转后立即检查当前缓冲后缀；命中规则就立即输出并消费已匹配的扭转。
- 规则输出统一为字符串，不保存输入法模式。
- 默认内置模拟功能规则：
  - `M → ⌫`：模拟删除，对应键盘 `J`；
  - `E → ␣`：模拟空格，对应键盘 `K`；
  - `S → ⇥`：模拟补全，对应键盘 `L`。
- `state` 状态匹配规则：当前保持未实现，暂不处理。

### 4.4 九宫格模式

- 可选任意逻辑面。
- 支持 QWERTY、字母顺序、数字 1–9 预设。
- 支持单格编辑、清空。
- 贴纸格同样只保存字符串。
- **待改进项**：当前九宫格模式的“目的 / 意义 / 功能不明确，需要改进”。

### 4.5 虚拟输入法

- 页面内虚拟输入法，不是系统输入法。
- 支持中 / 英模式切换。
- 英文模式：收到字符直接上屏。
- 中文模式：
  - 纯 ASCII 字母 / 数字视为拼音，显示候选；
  - 中文 / 符号等直接上屏。
- 当前不追求真实输入法体验，只做“映射规则给字符，输入法简单响应”。
- 拼音候选表当前为轻量演示表，后续可再扩展。

### 4.6 参考系与方向

手动模式：

- 用户固定正面 / 顶面颜色；
- 魔方中层转动后，自动寻找目标颜色当前所在的面；
- 键盘层映射跟随目标颜色。

方向模拟模式：

- **不读取真实设备方向 / 陀螺仪**；
- 使用固定 XYZ 与当前相机视角判断正面 / 顶面；
- 视角变化时实时更新正面 / 顶面。

方向模拟默认定义：

- 顶面 = 相机局部 +Y 对应的面；
- 正面 = 相机局部 +Z 对应的面。

### 4.7 配置与持久化

- 默认配置唯一来源：`src/mapping/defaultConfig.js`。
- 删除不再使用的 `config/default.mapping.json`。
- 所有配置变更自动保存到 `localStorage`。
- 配置导入后同样自动保存。
- 提供“重置所有配置”按钮，恢复默认配置并写回 `localStorage`。
- 提供 JSON 配置导入 / 导出。

### 4.8 侧栏

- 侧栏作为浮层，场景铺满全屏。
- 侧栏可收起、展开。
- 移动端侧栏按底部面板处理。

## 6. 规则与输入法边界

```text
魔方扭转 / 九宫格点击
        ↓
规则引擎输出一个字符串
        ↓
虚拟输入法解释并反应
```

规则层不保存：

- 中文 / 英文模式；
- 拼音字段；
- 候选列表。

输入法层负责：

- 当前模式判断；
- 是否显示候选；
- 是否直接上屏；
- 选择候选后输出最终文本。

## 7. 对外接口

页面加载后暴露 `window.CubeKeyboard`，稳定接口包括：

```js
// 魔方操作
CubeKeyboard.applyMove("F");
CubeKeyboard.applyMove("R'");
CubeKeyboard.applyMove("U2");
CubeKeyboard.turnRelative("F");
CubeKeyboard.resolveRelativeTurn("F", 1);
CubeKeyboard.getResolvedKeymap();
CubeKeyboard.resetCube();

// 配置
CubeKeyboard.loadConfig(json);
CubeKeyboard.exportConfig();
CubeKeyboard.saveConfig();
CubeKeyboard.resetConfig();
CubeKeyboard.setTurnDuration(180);

// 规则
CubeKeyboard.registerRule({
  id: "a",
  type: "turn-sequence",
  when: ["R", "B"],
  output: "a",
});
CubeKeyboard.removeRule("a");
CubeKeyboard.listRules();

// 九宫格
CubeKeyboard.registerStickerMap({
  id: "front-9",
  face: "F",
  cells: { "0,0": "a" },
});
CubeKeyboard.removeStickerMap("front-9");
CubeKeyboard.listStickerMaps();
CubeKeyboard.triggerSticker("F", { row: 0, col: 0 });
CubeKeyboard.setStickerCell("F", 1, 2, "X");
CubeKeyboard.clearStickerCell("F", 1, 2);

// 参考系与朝向
CubeKeyboard.setReference({ front: "white", up: "red" });
CubeKeyboard.setPoseDetectorMode("manual");
CubeKeyboard.setPoseDetectorMode("simulate");
CubeKeyboard.getPoseReference();
CubeKeyboard.getPoseDetection();
CubeKeyboard.resetView();
CubeKeyboard.setOrientationForTesting({ x: 0, y: 0, z: 0, w: 1 });

// 事件
CubeKeyboard.on("output", (output) => console.log(output));
CubeKeyboard.on("statechange", (state) => console.log(state));
CubeKeyboard.on("turnschange", (buffer) => console.log(buffer));
CubeKeyboard.on("configchange", (config) => console.log(config));
CubeKeyboard.on("referencechange", (reference) => console.log(reference));
```
